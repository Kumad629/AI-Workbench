# AI Workbench 网页对话助手

当前版本：桌面 **v0.14.0** / 扩展 **v0.12.0**。新增 ChatGPT、Gemini 网页文字收发及已加载历史同步。完全退出并重开工作台，在 Edge / Chrome 扩展管理页重新加载扩展，然后分别在专用对话页面点击扩展连接。

使用已有的 Gemini 网页账号，把当前对话预览后保存到本机 AI Workbench。也支持 X／推特内的 Grok（新增试用），无需模型 API Key。



## ChatGPT / Gemini 网页文字聊天（首版）

1. 完全退出并重开工作台，确认 v0.14.0；在 Edge / Chrome 的扩展管理页重新加载 AI Workbench，确认扩展 v0.12.0。
2. 分别登录 chatgpt.com 和 gemini.google.com/app，打开各自的一条专用对话；先处理已有草稿、附件及正在生成的回答。
3. 在对应原网页点击扩展 →「连接ChatGPT网页聊天」或「连接Gemini网页聊天」，保留该原网页与连接页。
4. 回工作台「网页账号」→ 对应的「进入 … 网页聊天」，等待已加载历史同步结束，再输入文字并发送。

每个平台单独绑定、接收和保存；两者可同时连接。本阶段只做独立网页文字聊天，尚未接入四家网页群发、@ 定向追问和显式转交另一模型回答。网页已有模型设置、历史和额度照常沿用；工作台不会自动把其他模型的回答加入问题。支持新建对话首次生成网址后继续接收、流式保存、停止接收、重新连接及 Markdown / JSON 导出。断线或重启不会自动重发，未识别唯一发送按钮时保留草稿。

首版 ChatGPT / Gemini 聊天只同步当前已加载的历史，不自动扫描合并，不支持从工作台发送图片。Gemini 原「加载并读取历史对话」存档入口仍保留，和实时聊天同步是两条入口。ChatGPT 先支持普通 /c/ 对话，暂不接入自定义 GPT / 项目路径；Gemini 先支持 /app/ 路径，不向只读分享页发消息。

已在隔离 Electron 数据和测试网页中验证实际本地连接链路；还未对用户登录账号发送真实消息，首次真实页面试用如有错误，请复制连接页诊断。实现及边界见 [ChatGPT / Gemini 适配记录](../STANDARD_CHAT_NOTES.zh-CN.md)。

## 图片发送与文字复制（桌面 v0.10.0 / 扩展 v0.9.0）

元宝、豆包网页账号聊天可在输入框 Ctrl+V 粘贴截图，或点击「添加图片」。发送前可预览、放大或移除；每次最多 3 张 PNG / JPEG / WebP，每张最多 2 MB。只有图片时会附上「请查看图片。」。发送的图片与消息一起保存在本机，重开后可查看，JSON 导出/导入保留图片；Markdown 导出内嵌图片数据，是否显示取决于阅读器。

请先重开工作台，在 Edge 的扩展管理页重新加载扩展至 v0.9.0，关闭旧连接页，再从元宝或豆包原对话重新连接。旧扩展仍可文字聊天，但图片发送会提示更新。原网页已有草稿/附件时先手动处理，保持网页与连接页打开。新图片先交给网页上传，确认出现预览且未显示上传状态后才提交；失败、无法确认或上传期间取消，不会降级为只发文字，也不会自动重发。真实网页可能更换上传结构，目前仍需用户实页验收。

各类消息提供「复制」按钮；可选中文字按 Ctrl+C，或右键复制。输入框右键支持粘贴、剪切、撤销和全选。此轮图片发送只接入元宝、豆包网页聊天；API 聊天仍为文本，历史扫描不补下载旧网页图片。

## 安装与配对

1. 打开新版 AI Workbench，进入左侧「网页账号」。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择本文件所在的整个 `browser-extension` 文件夹。
4. 将扩展固定到浏览器工具栏。
5. 在 AI Workbench 点击「复制配对信息」按钮，确认显示复制成功及字符数；点击浏览器扩展，在「连接本机应用」中粘贴，点「保存并检查连接」。

配对信息用于本机导入，以及向你明确连接的元宝页面转交工作台问题、接回回答，不是网页账号密码或模型 API Key。配对信息存于浏览器扩展本地存储，应用端的授权码经系统加密存储。可以在应用中重置连接码，使旧授权失效。

扩展目录随项目改名或移动后，需要在浏览器中重新加载新的文件夹。

## 元宝网页聊天（v0.5.0 试用）

1. 退出并重开工作台，在扩展管理页重新加载本扩展，确认版本为 0.9.0。
2. 使用已配对的浏览器登录 `https://yuanbao.tencent.com/`，打开一条对话或新建对话。请先处理输入区已有的草稿与附件，并等待正在生成的回答结束。
3. 在这个元宝标签页点击扩展 →「连接元宝网页聊天」。会打开「元宝网页连接」标签页；同一元宝标签页会复用已有连接页。
4. 回到工作台 →「网页账号」→「进入元宝网页聊天」。看到「浏览器已连接」后，在下方输入问题，点击「发送给元宝」。
5. 保持元宝和连接页打开，建议让元宝页面可见。回答会逐步回到工作台，支持表格、收藏、搜索和导出。

工作台只向你指定的元宝标签页发送。账号登录、验证码、网页额度和模型选择在元宝原网页处理；不复制 Cookie，也不使用元宝私有聊天接口。不要同时在原网页发送，以免无法关联本轮回答。

切换元宝对话后，请在连接页点击「连接 / 重新连接当前元宝页面」；再从工作台进入新网页聊天，或打开匹配的本地记录。连接页关闭或页面刷新导致接收中断时，请先检查原网页，不要盲目重发。工作台「停止接收」只中止本地接收，不撤回已发送内容。

如提示无法找到输入框、未识别到提问或无法读取正文，请查看连接页的「连接诊断」并复制其中内容。诊断只有版本、元素存在与消息数量，不含正文和凭据。若连接页提示任务未结束，可先在工作台「停止接收」再重新连接。

当前支持文本、单条会话和单个回答模式。连接时快速读取网页已加载历史；配合桌面 v0.8.0，可在工作台点击「自动加载并同步历史」自动滚动收集更早消息，也可选择「仅同步已加载」。v0.9.0 新增图片发送（见上文）；仍不支持群发、文档附件、语音、自动处理验证码或自动恢复发送。浏览器后台休眠可能使连接中断。本地模拟验证已覆盖流程，真实账号适配待用户首测。

## 保存

在你平时使用、已经登录的 Chrome / Edge 中打开一条 Gemini 对话：
- 点击扩展，再点击「加载并读取历史对话」。扩展会逐段向上加载，再向下核对消息，最长约 15 分钟。
- 保持 Gemini 标签页可见，不切换原对话、不手动滚动；可以关闭扩展面板，稍后在同一标签页重新打开查看进度和结果。
- 可点击「停止读取并预览已有内容」，结果会明确标注部分记录。
- 检查消息数、读取范围和首尾预览，确认第一条提问及最后一条回复后，再点击「保存到 AI Workbench」。读取范围会一同存入记录。
- 只想保存一段时，先选中文字，再点击「读取选中文字 / 已加载内容」。此入口不会自动加载历史。

点击保存后会自动分批传送；保持扩展面板打开即可看到进度。传送中断后可再次点击保存，已收到的相同批次会复用，不会重复生成会话。只有全部内容通过校验后才会显示为已保存。

保存成功后，应用显示一条本地对话记录。长原文分页阅读，收藏可以回到对应页，Markdown / JSON 导出包含全部原文。网页来源链接会一并保存。再使用现有收藏、笔记、搜索、Markdown / JSON 导出功能即可。

## 当前限制

- 这是用户主动触发的当前页面导入，不是实时镜像，不会自动同步账号全部历史。
- 继续提问仍在 Gemini 原网页完成，未实现工作台内的 Gemini 发送或四家网页群发。
- 支持 Gemini 和 X／推特内的 Grok（新增试用）；Grok 独立网站暂不支持。不读取密码、Cookie、账号配置或其他标签页。
- Gemini 页面结构会变化；历史读取依赖可识别的消息和滚动区域。无法识别时会提示改用选中文字 / 已加载内容。
- 自动滚动仍不能证明服务器上的全部消息都已加载：网页未提供历史总数，保存前请核对首尾。超时、无法滚动或消息衔接不明时会提示可能不完整。
- 图片、附件和原网页富媒体布局不会完整保留。单次支持最多 1000 万字符；原来的 48/50 万字符截断已取消。
- 本版本需要手动加载本地扩展，尚未上架商店。
- 自动化测试覆盖本地接收、校验、虚拟列表、异步历史加载、重复消息、停止、超时与桌面显示；尚未在你的已登录浏览器中验证实际扩展权限和当前 Gemini DOM。

浏览器权限：`activeTab`（主动点击时访问当前标签页）、`scripting`（执行固定的文本提取器和元宝页面输入／回答适配器）、`storage`（保存配对配置）、`http://127.0.0.1/*`（仅连接本机应用）。

## 配对信息只有几个字符时

请使用工作台的「复制配对信息」按钮。隐藏内容的密码框不适合直接按 Ctrl+C 复制；如需手动复制，请先点「显示」，再在框内按 Ctrl+A、Ctrl+C。扩展会显示粘贴的字符数和格式检查结果。

更新后请退出并重新打开 AI Workbench，并在浏览器的扩展管理页点击本扩展的「重新加载」。

## v0.3.1：滚动误停与计数说明

- “本次读取”是当次任务的消息总数：一条提问和一条回答分别计数。每次点击重新读取，不自动叠加或合并上次预览、本地旧记录。关闭后重开面板只恢复同一任务的进度。
- 修复历史向上加载后自动补偿滚动位置造成的误停。位置未变化时，还会检查正文和页面高度是否更新；实际无进展时最多进行两次小幅反向滚动重试。
- 读取结果显示提问数、回答数、字符数和容量上限。容量达到上限、消息衔接失败、超时、页面暂停刷新与滚动停滞分别提示。
- 预览中的“读取诊断”包含版本、计数、停止原因、耗时、重试次数和滚动尺寸，不包含正文、标题、网址或账号凭据。仍有遗漏时可复制诊断协助定位。
- 复现测试证实旧代码在“加载新消息但滚动坐标不变”的情况下提前停止；这不等于已确认用户真实 Gemini 页的所有遗漏都由此造成。
- 这是扩展修复，应用版本仍为 0.3.0。更新只需在扩展管理页重新加载扩展，并刷新原 Gemini 标签页。

## v0.4.0：X／推特内的 Grok（新增试用）

- Gemini 的特殊长对话问题已记录于项目根目录 KNOWN_ISSUES.zh-CN.md，按用户要求暂缓排查。

- 读取诊断独立于预览，失败时也可查看。只含固定结构的数量、页面就绪状态和读取阶段，不含正文、网址、标题或账号信息。

只读取，不会发送消息。多次同步不会重复添加同一段问答，已有收藏仍指向原消息。若消息衔接不确定，将提示并保留本地原记录。

本次范围为网页已加载内容，最多 1000 条、40 万字符；更早未加载消息需先在原网页向上翻看，再点同步。网页未提供历史总数与原消息时间，不能把已加载内容当成完整账号历史。

## v0.7.0：元宝自动加载历史

配合桌面 v0.8.0，新增「自动加载并同步历史」：
1. 重新打开工作台，在 Chrome / Edge 扩展管理页重新加载扩展，确认扩展版本为 0.7.0。

4. 扫描会向上加载，再向下检查到末尾；工作台显示方向、消息数与字符数。需要中止时点「停止同步」。

最多运行 15 分钟，最多收集 1000 条消息 / 40 万字符。达到时间或容量上限时，能保存的结果会标注为部分记录；消息衔接不明、页面切换或读取失败时，不强行写入本地。取消任务不会保存这次扫描结果。扫描期间不能从工作台发送问题。

相邻批次按顺序和正文重叠衔接，不依据易变化的页面索引覆盖消息，也不全局删除重复提问。完成或停止时，尽量按扫描前距底部的距离恢复滚动位置；虚拟列表变化较大时，位置不一定能精确还原。检查到页面顶部和底部不代表服务器历史完整，仍需核对首尾。

「仅同步已加载」保留快速读取方式。连接成功时仍只自动进行快速读取，完整滚动需点击上述扫描按钮。元宝适配器和连接页诊断版本均为 0.7.0。
